# Reglas y Comportamiento del Asistente (CDJ-Front)

## No ejecutar builds ni comandos innecesarios
- **NO ejecutar `yarn build`, `npm run build`, `ng build` ni comandos de validación tras editar archivos.**
- El autosave del IDE junto con el servidor de desarrollo (`yarn start`) aplican y reflejan los cambios automáticamente al instante.
- No ejecutar comandos de terminal salvo petición expresa del usuario.
